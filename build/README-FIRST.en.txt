CV Maker - By Farouk

CV Maker is a free, local-first desktop application for creating professional CVs.
Your CV projects, autosaves and logs stay on your computer by default.

Installation
1. Click Next.
2. Choose where CV Maker should be installed.
3. Choose whether you want Start Menu and Desktop shortcuts.
4. Keep "Associate .cvm files with CV Maker" enabled if you want to open CV Maker projects by double-clicking them.
5. Click Install.
6. Launch CV Maker.

No Python, MiKTeX, TeX Live or separate LaTeX installation is required for the packaged Windows release.
