CV Maker - Par Farouk

CV Maker est une application de bureau gratuite et locale pour créer des CV professionnels.
Vos projets, sauvegardes automatiques et journaux restent sur votre ordinateur par défaut.

Installation
1. Cliquez sur Suivant.
2. Choisissez le dossier d'installation de CV Maker.
3. Choisissez si vous souhaitez des raccourcis dans le menu Démarrer et sur le Bureau.
4. Gardez l'option d'association des fichiers .cvm activée si vous souhaitez ouvrir vos projets CV Maker par double-clic.
5. Cliquez sur Installer.
6. Lancez CV Maker.

Aucune installation séparée de Python, MiKTeX, TeX Live ou LaTeX n'est requise pour la version Windows distribuée.
