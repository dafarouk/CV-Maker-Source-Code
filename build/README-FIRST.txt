CV Maker 1.0.0 - By Farouk
=============================

WINDOWS INSTALLATION
--------------------
1. Extract the downloaded ZIP file.
2. Double-click:
   CV-Maker-Setup-1.0.0.exe
3. Follow the installer.
4. Keep the .cvm file association enabled if you want CV Maker projects
   to open by double-clicking them.
5. Launch CV Maker from the Start Menu or Desktop shortcut.

WINDOWS SECURITY NOTICE
-----------------------
CV Maker 1.0.0 is distributed without a paid code-signing certificate.
Windows may therefore display a SmartScreen warning.

If you downloaded CV Maker from the official GitHub release, choose
"More info" and then "Run anyway" to continue.

NO EXTRA SOFTWARE REQUIRED
--------------------------
The Windows release already includes its PDF engine.
You do not need to install Python, MiKTeX, TeX Live or Tectonic separately.

PRIVACY
-------
CV Maker is local-first. Your CV projects, autosaves and generated files
stay on your computer by default.

FRANCAIS
--------
1. Extrayez le fichier ZIP téléchargé.
2. Lancez CV-Maker-Setup-1.0.0.exe.
3. Suivez l'assistant d'installation.
4. Gardez l'association des fichiers .cvm activée si vous souhaitez ouvrir
   vos projets CV Maker par double-clic.
5. Lancez CV Maker depuis le menu Démarrer ou le raccourci Bureau.

Windows peut afficher un avertissement SmartScreen car l'application n'utilise
pas de certificat de signature de code payant. Si vous avez téléchargé CV Maker
depuis la release GitHub officielle, cliquez sur "Informations complémentaires"
puis "Exécuter quand même".

Aucune installation séparée de Python ou LaTeX n'est nécessaire.
